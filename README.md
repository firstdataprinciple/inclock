# InClock

Marketing website for **InClock** - an AI company that helps businesses discover, implement and run AI and Agentic AI solutions on clock time.

## Pages
Home, Services (+ Agentic AI, Generative AI, AI Consulting, Machine Learning, Data & AI Engineering, AI Ops), Industries, Case Studies, How We Work, About, Blog, Careers, Contact, Privacy, Terms.

## Develop
Static site generated by a dependency-free script:

```bash
python3 build.py        # writes ./site/
python3 -m http.server -d site 8000
```

Edit content and styles in `build.py`, then rebuild. Deploy `site/` to any static host (GitHub Pages, Netlify, Vercel, S3).

## Before launch
- Case studies are illustrative placeholders; replace with real work.
- Contact form uses `mailto:`; connect it to a form backend.
- Replace placeholder Privacy/Terms text and the hello@/careers@inclock.ai addresses.
